## Цель работы

Изучить функции и стандартные средства ввода-вывода языка C++, а также освоить запись и чтение структурированных данных из текстовых и бинарных файлов.

## Условие задания

Разработать программу для хранения сведений о пассажирских самолётах. Для каждого самолёта необходимо хранить следующие характеристики:

- модель самолёта;
- максимальная высота полёта;
- максимальная скорость полёта;
- максимальная дальность полёта;
- максимальное количество пассажиров.

Для хранения записей использовать контейнер `vector` и тип `string`. Предусмотреть запись и чтение данных в текстовом и бинарном форматах. Режим работы, формат файла и имя файла передаются программе через аргументы командной строки.

## Состав проекта

| Файл | Назначение |
|---|---|
| `main.cpp` | Исходный код программы |
| `airplanes.txt` | Пример файла с данными в текстовом формате |
| `airplanes.dat` | Пример файла с данными в бинарном формате |

## Запуск программы

Программа принимает три аргумента командной строки:

1. режим работы: `write` - запись или `read` - чтение;
2. формат файла: `text` - текстовый или `binary` - бинарный;
3. имя файла.

Примеры запуска:

**Запись в текстовый файл:**
```bash
lab2 write text airplanes.txt
```

**Чтение из текстового файла:**
```bash
lab2 read text airplanes.txt
```

**Запись в бинарный файл:**
```bash
lab2 write binary airplanes.dat
```

**Чтение из бинарного файла:**
```bash
lab2 read binary airplanes.dat
```


Для записи нужно выбрать `write` вместо `read`. При записи программа запросит количество самолётов и характеристики каждого из них.

## Пример исходных данных

В демонстрационных файлах содержатся сведения о трёх самолётах:

| Модель | Максимальная высота, м | Максимальная скорость, км/ч | Дальность, км | Пассажиры |
|---|---:|---:|---:|---:|
| Boeing 737-800 | 12500 | 842 | 5765 | 189 |
| Airbus A320 | 11800 | 840 | 6100 | 180 |
| Boeing 777-300ER | 13100 | 905 | 13650 | 550 |

## Результаты сравнения размеров файлов

Размеры файлов, приложенных к проекту:

| Формат | Файл | Размер |
|---|---|---:|
| Текстовый | `airplanes.txt` | 122 байт |
| Бинарный | `airplanes.dat` | 132 байт |

В данном примере бинарный файл занимает меньше места, поскольку числовые значения записываются в двоичном представлении, а не в виде текстовых символов. Размер файлов зависит от количества записей и длины названий моделей.
